# Добавление раздела "План лечения"

## Что добавлено

### 1. Для пациента (PATIENT)

Добавлен отдельный раздел **"План лечения"** в кабинете пациента:

```tsx
{patientInfo.treatment && (
  <div className="cabinet__section">
    <h2 className="cabinet__section-title">План лечения</h2>
    <div className="cabinet__treatment-card">
      <div className="cabinet__treatment-content">
        {patientInfo.treatment}
      </div>
    </div>
  </div>
)}
```

**Особенности:**
- Отображается только если врач назначил лечение
- Выделен в отдельную секцию для лучшей видимости
- Поддерживает многострочный текст
- Сохраняет форматирование (переносы строк)

### 2. Для врача (DOCTOR)

Добавлено отображение плана лечения в карточке каждого пациента:

```tsx
{patient.treatment && (
  <div className="cabinet__patient-treatment">
    <strong className="cabinet__patient-treatment-label">План лечения:</strong>
    <p className="cabinet__patient-treatment-text">{patient.treatment}</p>
  </div>
)}
```

**Особенности:**
- Отображается в карточке пациента
- Компактный вид с ограничением высоты (120px)
- Прокрутка при длинном тексте
- Визуально выделен фоном
