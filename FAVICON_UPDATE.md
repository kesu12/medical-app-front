# Обновление Favicon (иконки вкладки)

## Что изменено

### Favicon (иконка вкладки браузера)

**Было:**
```html
<link rel="icon" href="%PUBLIC_URL%/favicon.ico" />
```

**Стало:**
```html
<link rel="icon" href="%PUBLIC_URL%/logo_Done3.png" />
```

## Визуальное представление

### До:
```
┌─────────────────────────┐
│ [🔴] React App          │  ← Стандартная иконка React
└─────────────────────────┘
```

### После:
```
┌─────────────────────────┐
│ [H&L] Health & Life     │  ← Логотип Health & Life
└─────────────────────────┘
```

## Технические детали

### Файл
- **Путь:** `public/logo_Done3.png`
- **Формат:** PNG
- **Использование:** 
  - Favicon (иконка вкладки)
  - Apple touch icon (для iOS)
  - Логотип в Header

### Преимущества PNG для favicon
- ✅ Поддержка прозрачности
- ✅ Высокое качество
- ✅ Современные браузеры поддерживают PNG
- ✅ Один файл для всех целей

## Где отображается

1. **Вкладка браузера** - маленькая иконка рядом с названием
2. **Закладки** - иконка в списке закладок
3. **История** - иконка в истории браузера
4. **iOS Home Screen** - иконка при добавлении на главный экран
